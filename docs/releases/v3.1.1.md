# OpenTabletDisplay v3.1.1

The first release carrying the OpenTabletDisplay public identity end-to-end.

## Highlights

- Public installer/status/uninstall surfaces now say **OpenTabletDisplay** while 3.x internal FSDL identifiers remain stable for compatibility.
- Public package name is `OpenTabletDisplay-3.1.1-windows-x64.zip`.
- Detached SHA-256 checksum ships next to the release ZIP; the package still includes its full `SHA256SUMS.txt` manifest.
- Added device-testing documentation for real-world Android validation.
- No Lenovo-specific runtime ID or hard-coded tablet resolution was introduced.

## Compatibility

This is an in-place 3.x update. Existing Sunshine credentials, Moonlight pairings, virtual-display configuration ownership, enrollment state, and legacy internal FSDL paths/tasks are intentionally preserved.

## Known boundary

The wired stream itself travels through USB, but Moonlight/Sunshine identity still depends on an active physical Windows IPv4/default route.

## Windows trust

The project does not yet have an Authenticode signing identity. Verify the detached SHA-256 checksum and the in-package manifest when downloading a release.
